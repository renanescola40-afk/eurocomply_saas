# Phase 12 Kickoff

Phase 12 starts after the Phase 11 repository-side evidence handoff review surface.

## Entry commands

```bash
node scripts/dev/run-phase11-verify.mjs
```

## Initial direction

Phase 12 focuses on evidence handoff readiness review for organization reporting.

## Allowed work

- Add repository-side planning and validation artifacts.
- Identify safe readiness review touchpoints around evidence handoff review.
- Add static checkers or tests before additional runtime changes.
- Reuse the existing organization dashboard readiness signal and handoff review surface.

## Not allowed by this kickoff

- Product template changes.
- Email template changes.
- Document template changes.
- UI template changes.
- Local environment files.
- Provider credentials, private keys, service credentials, or customer data.

## Completion condition

Phase 12 kickoff is ready when this document and the phase check command exist.

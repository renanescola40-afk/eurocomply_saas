Date: 2026-10-06

Request only items not already evidenced.

1. General ledger / trial balance covering the relevant diligence period.
2. Monthly management P&L through the latest closed month.
3. Latest balance sheet.
4. Cash-flow statement or bank-to-GL cash reconciliation.
5. Bank statements for all seller accounts used for RISCK COMPLY activity.
6. A/R aging.
7. A/P aging.
8. Payroll/contractor ledger.
9. Debt/financing schedule and confirmations.
10. Fixed asset register.
11. Corporate-tax returns/assessments and current payment status.
12. VAT returns/recapitulative statements where applicable.
13. Current VAT registration evidence and VIES validation evidence.
14. Current Portal das Finanças certidão de dívida e não dívida.
15. Any outstanding tax notices, payment plans, disputes or guarantees.
16. Executed customer contracts/order forms and issued invoices outside Stripe.
17. Provider invoices not already included in the current data room.

## Do not request again

- Stripe LIVE zero activity/balance evidence already reconciled.
- Four Google provider invoices already credited.
- Existing bounded Vercel billing evidence already recorded.

This pack is intentionally minimal and excludes documents already evidenced.

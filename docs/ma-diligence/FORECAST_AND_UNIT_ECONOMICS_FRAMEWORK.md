# RISCK COMPLY — Forecast + Unit Economics Framework

Date: 2026-10-06

## Classification rule

Every number must be tagged:
ACTUAL, VERIFIED_ZERO, MANAGEMENT_ASSUMPTION, SCENARIO, or UNVERIFIED.

## Scenario model

Build monthly BASE, UPSIDE and DOWNSIDE cases with:
- opening customers;
- new customers;
- churned customers;
- closing customers;
- ARPA;
- MRR;
- annual contract billings;
- recognized revenue;
- payment fees;
- infrastructure;
- payroll/contractors;
- sales/marketing;
- legal/compliance;
- other OPEX;
- cash movement.

## Current measurable metrics

Stripe LIVE currently verifies:
- charges: 0 objects;
- invoices: 0 objects;
- customers: 0 objects;
- subscriptions: 0 objects;
- balance transactions: 0 objects;
- available EUR balance: 0;
- pending EUR balance: 0.

These are bounded Stripe facts, not company-wide historical performance.

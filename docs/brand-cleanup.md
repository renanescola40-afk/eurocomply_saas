# Brand cleanup

## Canonical product name

The customer-facing product name is **Risck Comply**.

Use this name in active public pages, metadata, README content, sales copy, trust pages, onboarding copy, dashboard labels, and support/security contact text.

## Legacy names

The repository is still named `eurocomply_saas` for continuity. Historical terms such as `EuroComply`, `RISCK COMPLY / EuroComply`, or old all-caps variants may exist in archived logs, migration history, old evidence, or code identifiers that would be risky to rename in a hygiene-only pass.

Do not introduce legacy naming into new customer-facing copy.

## Phase 1 cleanup scope

This hygiene pass focuses on credibility and brand alignment only:

- README uses Risck Comply as the active product name.
- Public metadata describes AI compliance and EU AI Act readiness instead of generic compliance/fiscal operations.
- Public footer copy is aligned with AI governance and evidence workflows.
- Route inventory names Risck Comply as the route quality contract.
- A focused Phase 1 test guards the active README, metadata, footer, and route inventory surfaces.

## Follow-up cleanup

Later phases should audit deeper legacy references before renaming code identifiers or historical evidence. Do not rename database objects, route names, auth callbacks, billing identifiers, or migrations without a dedicated compatibility plan.

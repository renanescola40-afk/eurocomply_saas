# Phase 1 Closeout Checklist

Use this checklist before marking Phase 1 complete.

## Required repository artifacts

- [ ] `package-lock.json` exists and was generated by npm.
- [ ] `docs/evidence/phase1/floating-deps.log` exists.
- [ ] `docs/evidence/phase1/npm-ci.log` exists.
- [ ] `docs/evidence/phase1/npm-audit.log` exists.
- [ ] `docs/evidence/phase1/typecheck.log` exists.
- [ ] `docs/evidence/phase1/test.log` exists.
- [ ] `docs/evidence/phase1/build.log` exists.
- [ ] `docs/evidence/phase1/lint.log` exists.
- [ ] `docs/evidence/phase1/dev-smoke.log` exists.

## Required command status

- [ ] `npm ci` exited with code 0.
- [ ] `npm audit --audit-level=moderate` exited with code 0, or findings have documented owners and remediation plans.
- [ ] `npm run typecheck` exited with code 0.
- [ ] `npm run test` exited with code 0.
- [ ] `npm run build` exited with code 0.
- [ ] `npm run lint` exited with code 0, or non-blocking warnings are documented.
- [ ] `npm run phase1:smoke` recorded a stable local HTTP response.
- [ ] `npm run phase1:evidence` exited with code 0.
- [ ] `npm run phase1:check` exited with code 0.

## Dependency closure

- [ ] Floating dependency specs were replaced with lockfile-resolved versions, or exceptions were documented.
- [ ] `docs/PHASE1_DEPENDENCY_REMEDIATION.md` is up to date.
- [ ] No dependency version was pinned by guesswork.

## Warning closure

- [ ] `docs/PHASE1_WARNING_TRIAGE.md` was applied to all warnings.
- [ ] Every accepted warning uses `docs/evidence/phase1/WARNING_EXCEPTIONS_TEMPLATE.md` or equivalent fields.
- [ ] No unresolved blocking warning remains.

## Final decision

Phase 1 is complete only when every required checkbox above is satisfied with real committed evidence.

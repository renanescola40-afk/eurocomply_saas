# FRIA Acceptance Checklist

A FRIA control may be promoted only when all applicable items are evidenced against the exact integrated SHA.

- [ ] Applicability rationale recorded and reviewed.
- [ ] Intended purpose and deployment context complete.
- [ ] Affected and vulnerable groups identified.
- [ ] Potentially affected rights mapped.
- [ ] Impact analysis includes severity, likelihood and residual impact.
- [ ] Mitigation plan has owners and deadlines.
- [ ] Human oversight and stop/escalation mechanisms documented.
- [ ] Complaints and redress route documented.
- [ ] Post-market monitoring linkage recorded.
- [ ] Data-protection coordination reviewed where applicable.
- [ ] Owner, reviewer and approver are distinct where required.
- [ ] Severe or uncertain cases have completed legal review.
- [ ] Evidence digests and version history validate.
- [ ] Migration passes in an isolated database.
- [ ] Positive and negative cross-tenant RLS tests pass.
- [ ] Exact-head lint, typecheck, tests and build pass.
- [ ] Human methodology review accepted.
- [ ] Canonical scorecard promotion records limitations.

Passing this checklist demonstrates evidence-backed workflow readiness, not guaranteed legal compliance or regulator acceptance.

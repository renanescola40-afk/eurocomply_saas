# Qualified Review Evidence Staging

Use this directory only for incomplete reviewer rosters and review packages under preparation.

Staging files do not receive product completion credit. Accepted evidence must pass the exact-SHA validator and then be moved through a reviewed pull request to `docs/compliance/evidence/accepted/`.

Never commit credentials, private identification documents, confidential legal advice or unredacted personal data. Qualification evidence should use safe references or redacted artefact identifiers.

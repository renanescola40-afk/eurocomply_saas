# Free Online Trust Signals

Status: LIVE EVIDENCE COLLECTION — no badge claim until verified.

This workstream collects public, no-cost trust signals that can improve buyer confidence without representing them as regulatory certifications.

## Included

- Green Web Foundation Green Web Check — verified green hosting evidence when the provider dataset returns `green=true`.
- MDN HTTP Observatory — public HTTP security-header grade and score.
- OpenSSF Scorecard — published software-supply-chain security score when the repository result is available.

## Claim rules

1. Never call these regulatory certifications, legal approvals, SOC 2, ISO 27001, ISO 42001, penetration tests, or CSA STAR.
2. Publish a badge only where the source service explicitly provides/permits a badge and the live result supports it.
3. Preserve source links so procurement reviewers can inspect the underlying result.
4. Re-check after material hosting, DNS, HTTP-header, repository-security or release-process changes.
5. A high score or A+ grade is a bounded technical signal, not proof that the full SaaS is secure.

## Priority

1. Green Web Foundation verified-green badge if live result is green.
2. MDN HTTP Observatory A/A+ hardening and evidence.
3. OpenSSF Scorecard public badge if a published result exists; otherwise improve publication/configuration without weakening repository controls.
4. Continue Internet.nl Website and Email 100% workstreams separately because they evaluate broader Internet standards.

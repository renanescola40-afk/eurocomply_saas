# Security FAQ

Status: procurement-safe FAQ. Answers must stay aligned with implementation and evidence.

## Do you have SOC 2?

Not currently. EuroComply must not claim SOC 2 until an approved report exists.

## Are you ISO 27001 certified?

Not currently. Certification must not be claimed without an active certificate.

## How is authentication handled?

EuroComply uses managed authentication and server-side session checks. Private workspace routes require an authenticated session.

## How is authorization handled?

Organization access is role-based. Current roles include owner, admin, editor, member and viewer.

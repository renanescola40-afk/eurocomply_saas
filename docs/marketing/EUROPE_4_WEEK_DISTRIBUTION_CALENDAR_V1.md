# Platform adaptation rules

## LinkedIn

Primary B2B authority channel.

Use:

- strong point of view;
- operational examples;
- regulatory nuance;
- native document carousels;
- founder/company expertise;
- discussion CTA.

Avoid hashtag stuffing.

## Instagram

Convert selected assets into:

- 6-8 slide carousels;
- short talking-head/explainer scripts;
- diagrams;
- checklist visuals.

Do not paste LinkedIn paragraphs into the caption.

## Facebook

Use selectively for:

- distribution;
- retargeting later;
- business-community sharing;
- event/webinar/resource promotion.

Not the primary organic growth channel.

## YouTube — later phase

Best first videos:

1. EU AI Act after August 2026 — what actually applies
2. How to build an AI system inventory
3. Provider vs deployer explained operationally
4. What counts as governance evidence

Use search-led titles rather than brand-only titles.

# Learning loop

After tracking is live, evaluate each market weekly on:

- impressions
- clicks
- CTR
- saves
- qualified comments
- profile visits
- branded-search change
- feature views
- template downloads
- demo starts
- demo submissions
- signup starts
- checkout starts

Do not optimize for likes alone.

## Decision rules

If a localized topic earns high search impressions but low CTR:

-> improve title/meta/message match.

If social earns saves/comments but no site visits:

-> improve CTA and commercial bridge.

If site visits rise but demo/signup remains flat:

-> CRO problem, not content-volume problem.

If one country produces materially more qualified conversion:

-> increase localized content allocation before increasing paid budget.

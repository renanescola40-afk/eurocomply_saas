## Asset order

### Asset A — Article 50 Evidence Operating Map

Best for:

- transparency questions;
- user-interaction AI;
- AI-generated/manipulated content;
- role/context questions;
- customer evidence discussions.

### Asset B — AI Governance Evidence Model

Best for:

- mature security/trust organisations;
- audit/customer review;
- stale or disconnected evidence;
- rationale/history problems.

### Asset C — AI Portfolio Governance Map

Best for:

- multiple products;
- multiple agents/use cases;
- shared provider/model dependencies;
- cross-country/customer portfolios.

### Asset D — Technical vs Operational Governance Map

Best for:

- agent platforms;
- observability/guardrail-heavy companies;
- runtime governance products;
- organisations where technical controls are mature but cross-functional workflow may be separate.

## Human-send workflow

```text
1. Re-check public signal before send
2. Select one legitimate business channel
3. Send personalised Touch 1
4. Offer the mapped asset
5. If recipient accepts -> send asset
6. Ask one diagnostic question
7. Record actual response code
8. Move to discovery only on real two-way signal
```

Do not send all four assets to one prospect.

---

## Response-to-next-action map

### `INTEREST_ASSET`

Send mapped asset. Ask one diagnostic question. No demo pressure.

### `INTEREST_DISCOVERY`

Use B2B Sales & Demo Playbook. Confirm buying group and current operating model.

### `EXISTING_SYSTEM_SOLVES`

Ask what works well and what system covers the workflow. Capture competitive/market learning. Do not argue.

### `WRONG_ROLE`

Ask whether there is a more appropriate function only if the recipient offers direction. Do not start internal-contact fishing.

### `PARTNER_INTEREST`

Move to Partner & Ecosystem motion, not sales pipeline.

### `COMPETITOR_OVERLAP`

Stop standard sales motion. Treat as market-learning/complementarity only if mutually useful.

### `NOT_PRIORITY` / `NO_FIT`

Close or nurture appropriately.

### `NO_RESPONSE`

Follow the controlled five-touch sequence; stop after the close-loop message.

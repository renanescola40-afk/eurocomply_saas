## Purpose

Provide a one-page governance canvas in French, German and Spanish for ecosystem contributions, workshops and account conversations.

The canvas is an operational aid. It is not legal advice, certification, automatic AI Act classification or a compliance guarantee.

Canonical model:

`SYSTEM / USE CASE -> OWNER -> PROVIDER / ROLE CONTEXT -> DECISION -> EVIDENCE -> REVIEW`

# FR — CANVAS DE GOUVERNANCE OPÉRATIONNELLE DE L’IA

## 1. Système / cas d’usage

- Nom du système IA
- Cas d’usage métier
- Processus / équipe
- Pays / région
- Statut du cycle de vie

## 2. Responsabilité

- Responsable métier
- Responsable technique
- Reviewer conformité / juridique
- Reviewer sécurité / privacy si pertinent

## 3. Fournisseur / contexte de rôle

- Fournisseur / modèle / dépendance
- Contexte de déploiement
- Rôle organisationnel à analyser
- Question de risque / transparence pertinente

## 4. Décision / rationale

- Décision de gouvernance
- Faits utilisés
- Rationale
- Question ouverte / exception

## 5. Preuves

- Preuve d’implémentation
- Preuve fournisseur / sécurité
- Preuve client / procurement si pertinente
- Emplacement de référence
- État de fraîcheur

## 6. Revue continue

- Dernière revue
- Prochaine revue
- Change trigger
- Action ouverte
- Historique de décision

### Question atelier

`Un autre reviewer pourrait-il reconstruire la décision sans demander le contexte à cinq équipes ?`

Safe footer:

`Outil de gouvernance opérationnelle. Ne remplace pas une analyse juridique et ne constitue pas une certification ou une garantie de conformité.`

# Asset / Software-IP Purchase Agreement — Master Draft

Status: DRAFT_READY / COUNSEL_REVIEW_REQUIRED / BUYER_SPECIFIC_INPUT_REQUIRED / SIGNATURE_REQUIRED

## Transferred assets
Only assets expressly listed transfer: source code/repositories, documentation, specified IP rights, domains, trademarks/brand rights, design assets, selected contracts, customer/pipeline rights to the extent assignable, data only where lawful, specified cloud/provider accounts where transferable.

## Excluded assets
Seller cash, tax records, unrelated business assets, personal accounts, non-transferable licences/accounts unless provider consents, privileged material unless expressly waived, production secrets and customer data except via lawful controlled migration.

## Assumed/excluded liabilities
Buyer assumes only liabilities expressly listed. Historical tax, undisclosed liabilities and unrelated seller obligations remain excluded except as negotiated.

## Price
Allocation by asset category [to be agreed with tax counsel]. Payment may be cash, deferred, earn-out and/or escrow.

## Transfer mechanics
IP assignment instruments; domain registrar changes; trademark filings/assignments if any; repository transfer; cloud account migration or new buyer accounts; data migration; contract novation/consents.

## Warranties
Authority; title to transferred assets; IP/software/OSS; privacy; security; contracts; taxes tied to transferred assets; no claims, all qualified by disclosure and negotiated limits.

## Data protection
No personal data transfers merely because assets are sold. Identify lawful basis, controller roles, notices, processor arrangements, migration security and deletion/retention obligations.

## Closing
Use SOURCE_CODE, DOMAIN, BRAND, CLOUD_ACCOUNT and other schedules in the disclosure master. No credential is placed in the agreement itself.

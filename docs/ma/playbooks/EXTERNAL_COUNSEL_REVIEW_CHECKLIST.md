# External Counsel Review Checklist

Status: DRAFT_READY

Corporate: seller entity, ownership, authority, constitutional documents, required resolutions, signatory power.
Structure: share/asset/IP/business/hybrid recommendation and mandatory-law issues.
IP: title chain, contributor/contractor assignments, trademarks/domains, OSS risk, source transfer wording.
Privacy/security: lawful data transfer, controller/processor changes, DPA/subprocessors, security representations.
Commercial: material contracts, assignment/change-of-control, customer restrictions, supplier consents.
Employment: employee/contractor transfer, restrictive covenants and creator/founder role.
Tax: direct/indirect tax, price allocation, withholding, escrow/earn-out/deferred tax.
Regulatory: FDI/merger control/sanctions/sector approvals if thresholds/facts trigger.
Definitive docs: warranties, disclosure standard, indemnities, caps, survival, knowledge/materiality, remedies.
Closing: conditions precedent, funds flow, registries/filings, notarisation/apostille if required.
Post-close: TSA, migration, retention, access removal, announcement/confidentiality.

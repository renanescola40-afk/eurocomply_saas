# Phase 8 Scope

Phase 8 defines the first executive reporting package workflow around organization readiness.

## Entry commands

```bash
npm run phase7:verify
npm run phase8:check
```

## Selected workflow

Executive readiness reporting package preparation.

## Allowed work

- Map the existing readiness summary and follow-up plan to executive reporting needs.
- Identify read-only reporting package touchpoints in the dashboard experience.
- Add validation artifacts before additional runtime changes.
- Add tests or static checkers for reporting package wiring.

## Not allowed

- Product template changes.
- Email template changes.
- Document template changes.
- UI template changes.
- Local environment files.
- Provider credentials, private keys, service credentials, or customer data.

## First milestone

Phase 8 initial scope is ready when kickoff, scope, and checks are wired through `npm run phase8:check`.

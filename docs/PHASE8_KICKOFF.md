# Phase 8 Kickoff

Phase 8 starts after the Phase 7 repository-side readiness follow-up workflow.

## Entry commands

```bash
npm run phase6:verify
npm run phase7:review
npm run phase7:verify
```

## Initial direction

Phase 8 focuses on executive reporting package preparation for organization readiness workflows.

## Allowed work

- Add repository-side planning and validation artifacts.
- Identify safe reporting package touchpoints around the readiness summary and follow-up plan.
- Add static checkers or tests before additional runtime changes.
- Reuse the existing organization dashboard readiness signal.

## Not allowed by this kickoff

- Product template changes.
- Email template changes.
- Document template changes.
- UI template changes.
- Local environment files.
- Provider credentials, private keys, service credentials, or customer data.

## Completion condition

Phase 8 kickoff is ready when this document and its checker exist.

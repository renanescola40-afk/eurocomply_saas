# Phase 1 Dependency Remediation

This document tracks the Phase 1 dependency cleanup required before the local technical base can be considered complete.

## Goal

Replace floating dependency specs with audited, lockfile-resolved versions instead of hand-picked guesses.

## Current known floating specs

The repository currently uses floating dependency specs that must be resolved through `package-lock.json` before completion:

- `dependencies.@emotion/is-prop-valid`: `latest`
- `dependencies.framer-motion`: `latest`
- `dependencies.vaul`: `latest`

## Required remediation flow

```bash
npm run supply-chain:lockfile
npm run supply-chain:floating-deps
npm ci
npm audit --audit-level=moderate
```

Then replace each floating spec with the exact version resolved and reviewed in `package-lock.json`.

## Acceptance criteria

Phase 1 dependency remediation is complete only when:

1. `package-lock.json` exists and was generated by npm.
2. `npm run supply-chain:floating-deps` reports no floating specs, or every remaining floating spec has a documented exception.
3. `npm ci` succeeds with the generated lockfile.
4. `npm audit --audit-level=moderate` is reviewed and any critical or high issues are fixed or documented with an owner.
5. The generated evidence is committed under `docs/evidence/phase1`.

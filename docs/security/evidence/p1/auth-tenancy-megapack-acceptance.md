# Auth and tenancy megapack acceptance

The package is eligible for merge only when the exact pull-request head passes all required repository and security checks.

Runtime promotion on `main` additionally requires the protected `Auth RBAC Tenant Proof` workflow to execute with complete production-environment synthetic fixtures.

## Required outcomes

- Disposable public signup succeeds.
- The disposable user is deleted during the same protected run.
- Owner, member and outsider synthetic sessions authenticate.
- Session refresh and logout succeed.
- Owner and member roles are observed in organization-scoped membership reads.
- Own-tenant reads succeed.
- Cross-tenant organization and membership reads are hidden.
- Cross-tenant membership insert, update and delete attempts affect no rows.
- Cross-tenant organization update and delete attempts affect no rows.
- Evidence is exact-SHA bound, redacted and generated by GitHub Actions.

## Explicit exclusions

OAuth callback and complete organization onboarding are not promoted by this package. They remain `NOT_VERIFIED` until real disposable journeys run successfully.

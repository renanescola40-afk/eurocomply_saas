It does not claim to validate unrelated runtime controls such as DAST, WAF, logging, rate limiting, backup/restore, SSO, MFA, step-up authentication, or production audit-chain verification.

Those controls remain tracked independently in `docs/security/evidence/p1/P1_EVIDENCE_INDEX.json`.

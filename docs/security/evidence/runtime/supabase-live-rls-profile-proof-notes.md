# Supabase live RLS profile proof gate

Status: Open until generated by a live Supabase run.

The P0 Supabase live RLS evidence checker now rejects `Complete` / `passed` evidence unless `profiles` includes machine-readable passing cases for:

- `rls_enabled`
- `cross_tenant_read`
- `cross_tenant_insert`
- `cross_tenant_update`
- `cross_tenant_delete`
- `same_tenant_read`

This prevents the enterprise readiness gate from accepting catalog-only RLS coverage for user-scoped profile data. The remaining completion step is to extend the live runner fixture to generate these `profiles` cases against the target Supabase project and commit the resulting `docs/security/evidence/runtime/supabase-live-rls-validation.json` only when the live run passes.

# Phase 1 Evidence

This folder tracks the evidence required to mark Phase 1 as complete.

## Required generated artifact

- `package-lock.json` generated by npm from the repository root.

## Capture helpers

After generating the lockfile, run:

```bash
npm run phase1:capture
npm run phase1:smoke
```

The helpers record command outputs in this folder. Keep real outputs only.

## Required command outputs

Attach or paste the real output for each command below before marking Phase 1 complete:

```bash
npm run supply-chain:floating-deps
npm ci
npm audit --audit-level=moderate
npm run typecheck
npm run test
npm run build
npm run lint
npm run dev
```

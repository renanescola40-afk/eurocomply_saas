## Required runtime evidence

A paid public launch requires these files to exist and pass for the same commit and target runtime:

```text
docs/security/evidence/runtime/deployment-smoke-validation.json
docs/security/evidence/runtime/rollback-dry-run-validation.json
docs/security/evidence/runtime/production-final-validation.json
```

The files must be generated by the release command, not manually edited.

## Required command

```bash
npm run release
```

The command executes these critical gates:

1. `npm ci`
2. `npm run lint`
3. `npm run typecheck`
4. `npm run test`
5. `npm run test` again
6. `npm run build`
7. `npm run security`
8. `npm run release:deployment-smoke`
9. `npm run release:rollback`
10. `npm run release:readiness`

The requested self-recursive `npm run release` step is intentionally expanded to concrete release subcommands to prevent an infinite loop.

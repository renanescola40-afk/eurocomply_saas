# Controlled Disclosure and Confidentiality Matrix
Date: 2026-10-14 | OWNER_APPROVAL_REQUIRED

| Class | Examples | Release gate |
|---|---|---|
| INITIAL_REVIEW | qualified product overview; sanitized high-level architecture; carefully qualified security overview | identified recipient + specific owner approval |
| NDA_REQUIRED | exact-SHA security evidence, architecture details, privacy/data-processing docs, detailed financials, contract status | signed NDA, purpose limitation, least privilege, approval |
| RESTRICTED_LATE_STAGE | sanitized source, Git history, RLS and tenant isolation tests, detailed risk register, handover details | approved diligence scope, read-only access, log access and counsel review |
| NEVER_AS_IS | passwords, tokens, production logs with PII, raw exploit reproduction, customer records, privileged counsel advice | redact or withhold; no automatic access |

This repository branch is **not** a hosted data room and grants no third-party access. No notification, invitation, email or external disclosure is authorized.
